POD Wedding Commerce OS v29

1. cp .env.example .env
2. Set APP_ENCRYPTION_KEY and ADMIN_API_KEY.
3. npm install
4. npm start
5. Open http://localhost:3000/

Customer flow: Start designing → sign in/register → Studio → Request order → account.html.
Admin flow: http://localhost:3000/admin.html → Studio / 账号.
Real email delivery requires SendGrid or Postmark credentials; without them development records the email attempt as not_configured.
