Install

  1. Install Pod.AI from the App Store listing (or your test install link).
  2. Open Apps → Pod.AI in the admin (embedded dashboard).
  3. Complete the setup checklist on the Overview tab.

Enable the chat on your storefront

  1. Go to Online Store → Customize.
  2. Open App embeds.
  3. Turn on Pod.AI Chat and Save.
  4. Optional: set colour, position, title or greeting in the embed settings or in Apps → Pod.AI → Settings.

FAQ

Do I need an AI / LLM key?
No. Product, shipping, policy and order answers work from your store data without a key. An optional LLM can answer open questions when you turn it on.
Which languages are supported?
English, German, French, Italian and Chinese are built in. More languages work when an LLM is enabled.
How does order lookup work?
Shoppers provide order number and e-mail. The App checks they match, then shows status and tracking when available.
Where do handoffs go?
Apps → Pod.AI → Handoffs. The shopper can leave a reply e-mail; your team answers by e-mail.
Is customer data shared across stores?
No. Data is separated per shop and deleted after uninstall when the platform sends its shop-deletion request. See the Privacy Policy.
