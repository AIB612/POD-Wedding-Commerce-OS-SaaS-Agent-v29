一、系统架构概览
--------------------------------------------------------------------------------

【前端（静态文件，由 Node 服务直接提供）】
- index.html / home-chat.js  首页：场景、产品墙、页头“Ask POD.AI”主图区对话面板
                             （无悬浮气泡；/?ask=1 打开）
- studio.html / studio*.js   设计工作室（场景套装、定制、定价、寄送、包装、确认）
- checkout.html / .js        结账（联系 → 配送 → 支付 → 确认），金额由服务器报价
- account.html / account-*.js 客户账户（订单、方案、Proof、地址）
- proof.html                 效果图确认页
- payment-success.html       支付结果页
- agent.html                 Agent 产品页（实时数字来自 /api/pod-agent/status）
- admin.html + admin-sections.js  后台（21 个分区，见 docs/ADMIN_UX.md）
- admin-login.html           后台登录 /admin/login
- header.js / footer.js / cart.js / i18n.js（中/英/德）/ mobile.css
- shipping / returns / terms / privacy / imprint .html  政策与法律页
- admin-app/                 React 后台源码（生产未构建，/admin-app/ 返回 404）

【后端（server/）】
- app.js（ESM 入口）/ cpanel-start.cjs（cPanel Passenger 入口）/ create-app.js
- routes/public.js     页面、结账、PayPal/TWINT、订单查询、Proof、邀请函、
                       /api/agent/chat（旧）、/.well-known/*
- routes/account.js    客户登录（Google / Shop / 邮箱码）与账户 API
- routes/studio.js     Studio 项目、报价、样机
- routes/seller.js     商家素材与发布到 Shopify
- routes/admin.js      /api/saas/*（后台，requireAdmin；写操作 requireApproval）
                       /api/agent/ops（后台运营 Agent）
- routes/logistics.js  /api/saas/carriers/*（YunExpress / 4PX 运单、面单、追踪）
- routes/carrier-rates.js  Shopify CarrierService 回调
- routes/shopify-app.js / webhooks.js  Shopify App OAuth、嵌入页、Webhook
- pod-agent/           客户聊天 Agent（/api/pod-agent/*）+ widget.js
- services/            结账报价、费用与税、价目表、优惠码、邮件、Proof、RSVP 等
- logistics/           承运商适配器（yunexpress.js、fourpx.js、mock.js）、轮询
- connectors/          PayPal、TWINT（骨架）、LLM、营销/社媒/税务适配位
- saas-store.js        业务数据（内存 + STORE_PERSIST_PATH JSON 持久化）
- db/                  SQL 适配（Shopify 集成表；SQLite 文件或 MySQL）
- jobs/scheduler.js    承运商轮询、汇率同步

【数据流】
首页 / Studio → 购物车 → 结账（服务器报价）→ PayPal / TWINT → 订单 →
效果图（Proof）→ 生产 → 承运商运单（YunExpress / 4PX）→ 追踪 → 签收
订单状态：Needs approval → Proof ready → Approved（或 Changes requested）→
Production → Ready to ship → Label created → Shipped → Delivered（或 Cancelled）

五、部署（摘要，详见 docs/DEPLOYMENT.md）
--------------------------------------------------------------------------------

- 生产：cPanel / CloudLinux Node.js Selector（Passenger，Node 22），
  应用目录 ~/pod-wedding，启动文件 server/cpanel-start.cjs。
- 发布：推送 main 后在服务器执行
    cd ~/pod-wedding && git pull &&
    cloudlinux-selector restart --json --interpreter nodejs --app-root pod-wedding
  （不是 Render 自动部署；不要直接 node/npm start 重启生产。）
- 本地开发：
    npm install
    cp .env.example .env   # 至少设置 ADMIN_API_KEY、APP_ENCRYPTION_KEY
    npm start              # http://localhost:3000
